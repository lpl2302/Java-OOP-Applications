# Java OOP Applications

A collection of Java applications exploring object-oriented programming, software design, and practical problem-solving.

The projects demonstrate how fundamental programming concepts can be applied to build structured applications, manage data, and implement interactive functionality.

## Projects

### 1. Student Record Management

A Java application for managing student information and academic progress.

**Key features:**
- Student profile creation and management
- Personal identification validation
- Bachelor's and master's degree credit tracking
- Thesis information and graduation year management
- Data encapsulation and input validation

### 2. Academic Management System

An object-oriented implementation of academic administration components, including course assignments and personnel management.

**Key concepts:**
- Class hierarchies and inheritance
- Abstract classes and interfaces
- Course and personnel relationships
- Employee identification and validation
- Flexible payment calculations using different payment models

### 3. Employee Payment Management

A Java implementation of employee compensation logic using reusable interfaces and object-oriented design.

**Key features:**
- Hourly payment calculations
- Support for interchangeable payment implementations
- Employee data management
- Encapsulation and input validation

### 4. Hangman Word Game

An interactive command-line word guessing game built with Java.

**Key features:**
- Random word selection from external text files
- Letter-by-letter guessing
- Remaining-attempt tracking
- Dynamic word masking
- Win and loss detection
- Input validation
- Word filtering by length and character patterns

## Technologies

- **Language:** Java
- **Core concepts:** Object-oriented programming, inheritance, polymorphism, abstraction, interfaces
- **Data structures:** Lists and collections
- **File handling:** Java I/O
- **Development tools:** Git, Maven, Java IDEs

## Technical Highlights

**Object-Oriented Design**

Applied inheritance, abstraction, encapsulation, and interfaces to organize application logic into reusable components.

**Input Validation**

Implemented validation rules for personal identification, dates, numeric values, and user input.

**File-Based Data Processing**

Used Java's file handling capabilities to load and process external word lists.

**Interactive Applications**

Developed console-based functionality with user input handling, game-state management, and dynamic output.
